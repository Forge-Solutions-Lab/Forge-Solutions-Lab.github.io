Welcome to the official organization repository of **Forge Solutions Lab** — a student-led software engineering team building robust web applications and algorithmic solutions as part of a university startup simulation project.

Our mission is to design clean, functional software while learning real-world engineering practices — from version control and CI/CD to team collaboration and product deployment.

## Getting Started (Local Development)

```bash
# Clone the repository
git clone https://github.com/Forge-Solutions-Lab/Forge-Solutions-Lab.github.io.git
cd Forge-Solutions-Lab.github.io

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
